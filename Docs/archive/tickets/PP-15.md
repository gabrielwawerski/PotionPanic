## Description

Create blockout-quality interaction prompt UI that clearly communicates when a
current interaction target is available and what action the player can take,
while leaving targeting and interaction ownership in gameplay systems.

## Acceptance Criteria

- [ ] A valid current interaction target produces a visible prompt.
- [ ] No current target produces no active interaction prompt.
- [ ] Prompt text/input indication is readable during normal gameplay.
- [ ] Prompt show/hide behavior follows authoritative interaction state.
- [ ] UI does not select targets or invoke gameplay rules on its own.
- [ ] Presentation remains blockout quality and does not require final menu/HUD polish.

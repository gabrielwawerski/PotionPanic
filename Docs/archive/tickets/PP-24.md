## Description

Integrate the Milestone 3 item data, inventory, stations, presentation assets,
and carried-item HUD into the first complete non-disaster gameplay loop. This is
the Milestone 3 exit gate and should prove the accepted path without bypassing
the reusable interaction or inventory contracts.

## Acceptance Criteria

- [ ] `PP-17` through `PP-23` are complete before final milestone validation.
- [ ] The player begins the validation path with empty inventory.
- [ ] Interacting with the Blue Mushroom station places Blue Mushroom in `PlayerInventory`.
- [ ] The carried-item HUD updates to Blue Mushroom.
- [ ] Interacting with the Brewing Station consumes/replaces Blue Mushroom and leaves Cooling Potion carried.
- [ ] The carried-item HUD updates to Cooling Potion.
- [ ] Ingredient pickup while already carrying an item is rejected.
- [ ] Brewing with no ingredient is rejected.
- [ ] Inventory never contains both an ingredient and potion simultaneously.
- [ ] The loop uses the common `IInteractable`, `PlayerInventory`, and configured item-data path.
- [ ] No substantial missing Patro/Gabro implementation is hidden inside this Team ticket.

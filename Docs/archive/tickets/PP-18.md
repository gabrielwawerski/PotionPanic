## Description

Implement `PlayerInventory` as the authoritative owner of the player's MVP
single carried-item state. The player may carry one ingredient or one potion,
never both, and presentation must be able to observe state changes without
owning inventory rules.

## Acceptance Criteria

- [ ] Empty inventory is represented correctly.
- [ ] The player can carry one ingredient.
- [ ] The player can carry one potion.
- [ ] The inventory never contains both an ingredient and a potion simultaneously.
- [ ] Acquiring a second item while occupied is rejected unless the operation is the accepted ingredient-to-potion replacement.
- [ ] A carried ingredient can be replaced by its brewed potion.
- [ ] The carried item can be consumed/cleared when gameplay requires it.
- [ ] Inventory changes can be observed by UI/presentation without giving presentation ownership of gameplay state.
- [ ] `PlayerInventory` contains no station-specific gameplay logic.

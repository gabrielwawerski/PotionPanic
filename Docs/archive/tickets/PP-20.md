## Description

Implement the reusable `BrewingStation` interaction that converts the currently
carried ingredient into its configured resulting potion. Brewing must remain
data-driven and use the common interaction/inventory path.

## Acceptance Criteria

- [ ] `BrewingStation` participates through the common `IInteractable` path.
- [ ] Interaction with no carried ingredient is rejected.
- [ ] The station reads the carried ingredient's configured resulting `PotionData`.
- [ ] Successful brewing replaces/consumes the ingredient and leaves the resulting potion carried.
- [ ] The inventory never contains both the source ingredient and resulting potion simultaneously.
- [ ] Brewing does not hardcode Blue Mushroom or Cooling Potion recipe logic.
- [ ] Invalid inventory state does not produce a duplicate or unintended potion.

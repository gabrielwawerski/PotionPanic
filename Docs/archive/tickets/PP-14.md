## Description

Implement the reusable Milestone 2 interaction foundation so the player can
detect, select, and invoke one nearby `IInteractable` without embedding
station- or disaster-specific behavior inside the interaction controller.

## Acceptance Criteria

- [ ] Interactable gameplay objects can participate through the common `IInteractable` contract.
- [ ] The player can detect nearby valid interactables.
- [ ] One current target is selected deterministically when multiple candidates are valid.
- [ ] Pressing Interact invokes only the selected target.
- [ ] Leaving range or invalidating a target clears it correctly.
- [ ] No valid target results in no interaction action.
- [ ] Interaction state required by presentation can be observed without UI owning target-selection logic.
- [ ] `InteractionController` contains no ingredient-station, brewing-station, or disaster-specific gameplay rules.

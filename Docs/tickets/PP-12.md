## Description

Implement the Milestone 1 player movement foundation using `PlayerController`
and `CharacterController`. Keep movement world-aligned on X/Z, normalize
diagonal input, and configure the minimal player runtime setup needed to collide
with the laboratory boundaries.

## Acceptance Criteria

- [ ] WASD/player move input moves the player on world X/Z axes.
- [ ] Diagonal input does not increase movement speed.
- [ ] Movement uses `CharacterController`, not `Rigidbody` gameplay.
- [ ] Player collision prevents movement through configured laboratory boundaries.
- [ ] Move speed is configurable without changing movement code.
- [ ] Milestone 1 movement does not introduce:
  - [ ] sprint
  - [ ] jump
  - [ ] mouse look
  - [ ] camera-relative movement
  - [ ] camera follow behavior
  - [ ] unrelated interaction logic
- [ ] The final CharacterController setup required for Milestone 1 is recorded in the ticket notes during implementation.
